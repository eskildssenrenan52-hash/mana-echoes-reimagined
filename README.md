# Mana Echoes Reimagined

https://github.com/eskildssenrenan52-hash/mana-echoes-reborn traga o conteúdo do repo que é um jogo baseado no do repo https://github.com/sourceofmana/sourceofmana. Eu quero que todo o design e botões do jogo sejam feitos com IA geradora de imagens. Depois disso quero que crie biomas novos no jogo e deixe o mapa muito maior e mais diverso, 100x mais bonito, animado, e detalhado
